# SkillPilots Responsive Design Project

This front-end demo recreates the supplied screenshot's Career Path page and Day 20 task: **Responsive Design with Media Queries**.

## Files
- `index.html` — page structure and task content
- `style.css` — desktop, tablet, and mobile responsive styling
- `script.js` — implementation-steps modal controls

## Run in VS Code
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or install the Live Server extension.
4. Right-click `index.html` and choose **Open with Live Server**.

## Breakpoints
- Below 900px, the two content panels become one column.
- Below 600px, the sidebar is hidden and spacing and text sizes adapt for mobile.

## Note
This is a front-end recreation based on the screenshot, not the original SkillPilots source code. It does not include the real site's backend, login, database, or APIs.
